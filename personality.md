⚠️ Этот файл лежит в репозитории. Если твой форк **публичный**, его видят все.
**Не вставляй сюда свою настоящую личность коуча**, если репозиторий публичный.

**Куда класть свою личность:** приватно, в Railway → Variables → переменная
`COACH_PROMPT`. Бот берёт `COACH_PROMPT` в первую очередь, а этот файл только
запасной пример. Так твой личный промпт не утечёт на GitHub.

*(Если ты сделала свой репозиторий приватным, можешь спокойно вписать личность
прямо сюда, вместо переменной.)*
