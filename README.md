# Coach Bot Lite 🌿

Твой коуч отдельным ботом в Telegram. Пишешь ему, он отвечает твоим голосом
и работает сам, 24/7. Минимальная версия: **без базы данных**, чтобы запуститься
за 10-15 минут. Память и расписание добавишь потом.

> Из практикума «AI для лучшей жизни». Коуча (его личность) ты собираешь сама,
> а этот репозиторий превращает его в живого бота в Telegram.

---

## Что это и чего пока нет

- ✅ Свой бот в Telegram, **сам отвечает** как собеседник.
- ✅ Живёт на сервере, работает, **когда твой компьютер выключен**.
- ✅ Личность берётся из **твоего** промпта коуча (файл `personality.md`).
- ⚠️ **Пока без памяти:** забывает разговор при перезапуске. Базу подключишь потом.
- ⚠️ Сам по утрам пока не пишет (это добавляется вместе с памятью и расписанием).

---

## Как запустить: позови своего агента

Программировать не нужно, всё делает Claude, ты отвечаешь.

1. Нажми **Fork** (вверху справа), это твоя копия.
2. Склонируй её и открой папку в [Claude Code](https://claude.ai/code)
   (или в Claude Desktop с доступом к файлам).
3. Напиши агенту: **«начнём»**.

Claude прочитает [`CLAUDE.md`](CLAUDE.md) и проведёт по шагам:
бот в @BotFather → ключ Claude → твоя личность → деплой на Railway → проверка.

```bash
git clone https://github.com/ТВОЙ_ЛОГИН/coach-bot-lite
cd coach-bot-lite
claude            # откроется Claude Code
# дальше просто напиши: начнём
```

## Что понадобится

| Что | Зачем | Цена |
|-----|-------|------|
| Telegram + @BotFather | сам бот | бесплатно |
| [Anthropic API](https://console.anthropic.com) | мозг (Claude) | ~$5 на старт |
| [Railway](https://railway.app) | где бот живёт 24/7 | ~$5/мес |

Три переменные при деплое: `TELEGRAM_BOT_TOKEN`, `ANTHROPIC_API_KEY`,
`ALLOWED_USER_IDS` (твой Telegram id, чтобы отвечал только тебе).

## Сделай его своим

Один файл: [`personality.md`](personality.md). Вставь туда свой промпт коуча
с практикума, целиком. Это и делает бота именно твоим коучем.

---

## Безопасность

- Токен и ключ вписываешь **только в Variables на Railway**, не в код.
- Обязательно заполни `ALLOWED_USER_IDS` своим id (узнать: @userinfobot),
  иначе бот ответит любому и чужие будут тратить твой баланс Anthropic.
- `.env` и сессии в `.gitignore`, наружу не уходят.
